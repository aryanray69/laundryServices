# Laundry Services Landing Page

## Project Overview

This project is a simple Laundry Services Landing Page created using HTML and CSS. It features a navigation bar, a hero section, a call-to-action button, and an image representing laundry services.

## Features

* Responsive navigation bar
* Hero section with promotional content
* Styled call-to-action button
* Hover effects on navigation links and button
* Custom fonts using Google Fonts
* Viewport units (vh and vw) for layout sizing

## Technologies Used

* HTML5
* CSS3
* Google Fonts (Roboto & Poppins)

## Project Structure

```text
LaundryServices/
│
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Download or clone the project files.
2. Ensure `index.html` and `style.css` are in the same folder.
3. Open `index.html` in any modern web browser.
4. The webpage will load automatically.
